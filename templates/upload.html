Two Sum

Given an array of integers and a target value, return indices of the two numbers that add up to the target.

Example: nums = [2, 7, 11, 15], target = 9 → [0, 1]

Python 
def two_sum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        diff = target - num
        if diff in seen:
            return [seen[diff], i]
        seen[num] = i
    return []
